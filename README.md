# BIZSIM — Business Intelligence & Strategic Case Simulation Platform

Zero-login, local-first corporate case simulation and live company intelligence engine.

## Supported Platforms
1. **Web / Offline PWA**: Open `web/index.html` directly in any browser or serve via `npx serve web`.
2. **iOS & Android Native Apps**: Powered by Capacitor (`npx cap add ios && npx cap add android`).
3. **Linux (.AppImage / .deb), macOS (.dmg), Windows (.msi)**: Powered by Tauri (`cargo tauri build`) or Electron (`npm run electron`).
4. **Autonomous Python SEC EDGAR & Web Crawler**: Located in `backend-crawler/edgar_ingest_pipeline.py`.
